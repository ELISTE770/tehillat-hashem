# תהילת השם — גרסת Windows

סידור "תהילת השם" כאפליקציית Windows מתקדמת, עם 29 תפילות שנבנות ומורכבות דינמית לפי היום והמועד העברי.

הריפו הזה משמש להפצת קבצי ההתקנה וההפצה. **הגרסאות להורדה בלשונית [Releases](../../releases).**

---

## 🌟 חידושים ותכונות מרכזיות (גרסה 1.4.0)

- **ממשק עברי מלא וטהור** — חוויית שימוש אותנטית בעברית צחה וקולחת, ללא רכיבים מיותרים.
- **הדגשת קטעים ממוקדת (Targeted Passage Overlays)** — כאשר יש הוספה מיוחדת בתפילה (כגון יעלה ויבוא, על הניסים, עננו, נחם, זכרנו לחיים, ספירת העומר), הקטע הספציפי מודגש בדיוק של 100% עם תווית עדינה וגלילה ממורכזת, במקום לסמן את כל מסגרת הדף.
- **רצועת דפדוף ימים מאובטחת (`DayBar`)** — אפשרות לצפות מראש בסדרי תפילה של ימים קודמים או באים, עם איפוס אוטומטי בהפעלה חוזרת ובנר אזהרה הלכתי מובהק למניעת טעויות.
- **לוח שנה עברי ויזואלי (`HebrewCalendar`)** — תצוגת חודש עברי מלאה עם גימטריה, סימון ראשי חודשים, שבתות, חגים וימי צום.
- **פאנל הדפסה וייצוא PDF מקצועי (`PrintPanel`)** — ייצוא ישיר של תפילות שלמות או קטעים נבחרים לקובץ PDF באיכות A4 חדה או שליחה ישירה למדפסת.
- **זמני הלכה מורחבים ותמיכה רב-עירונית** — 11 זמני יום הלכתיים מדויקים בערים מרכזיות בישראל ובעולם (ירושלים, בני ברק, צפת, תל אביב, חיפה, באר שבע, ניו יורק, לונדון, פריז, בואנוס איירס, מוסקבה ועוד) לפי אזורי זמן רשמיים.
- **תזכורות תפילה חכמות והודעות פנימיות** — מערכת התראות Toast פנימית לתפילת מנחה לפני שקיעה, ספירת העומר והוספות מיוחדות.
- **סימנייה חכמה ושמירת מקום** — שמירת העמוד המדויק שבו עצרת וחזרה אליו בלחיצה אחת.

## 🚀 התקנה

הורידו את הגרסה הרצויה מקבצי ה-Release:
1. **התקנה מלאה:** `TehillatHashem-Setup-1.4.0.exe` (יוצרת קיצור דרך ותומכת בעדכונים אוטומטיים).
2. **גרסה ניידת (Portable):** `TehillatHashem-Portable.exe` (פועלת מיידית ללא צורך בהתקנה).

> [!NOTE]
> בהרצה ראשונה ייתכן ש-Windows Defender SmartScreen יציג התראה על תוכנה חדשה — יש ללחוץ על **מידע נוסף (More info) ← הפעל בכל זאת (Run anyway)**.

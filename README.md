# תהילת השם — גרסת Windows

סידור "תהילת השם" כאפליקציית Windows, עם 29 תפילות שנבנות לפי היום העברי.

הריפו הזה משמש להפצת קבצי ההתקנה בלבד. **הגרסאות בלשונית
[Releases](../../releases).**

## מה מיוחד כאן

זו אינה סריקה סטטית. האפליקציה מרכיבה כל תפילה לפי התאריך:

- **התפילה של עכשיו** נבחרת לפי זמני היום — עלות השחר, חצות, שקיעה
- **שחרית** נבנית אחרת בחנוכה, ראש חודש, חול המועד פסח, חול המועד סוכות,
  תענית, פורים ויום רגיל — כולל שיר של יום וקריאת התורה של שני וחמישי
- **הוספות היום** מסומנות: יעלה ויבוא, על הניסים, עננו, המלך הקדוש,
  נחם, זכרנו לחיים ועוד — עם קפיצה ישירה לעמוד
- **ספירת העומר** נספרת לפי הלילה הנוכחי
- מנהג ארץ ישראל או חוץ לארץ, לפי העיר שנבחרה

## התקנה

הורידו את `TehillatHashem-Setup-x.y.z.exe` מהגרסה האחרונה והריצו.
ההתקנה שואלת אם ליצור קיצור דרך בשולחן העבודה.
קיימת גם גרסה ניידת שרצה ללא התקנה.

בהרצה הראשונה Windows SmartScreen יזהיר שהקובץ אינו חתום —
**מידע נוסף → הפעל בכל זאת**.

## עדכונים

הגרסה המותקנת בודקת כאן גרסאות חדשות בעת הפעלה, מורידה ברקע,
ומתקינה רק לאחר אישור.

## מקור התוכן

התוכן הוא עמודי הסידור כתמונות, שחולצו מאפליקציית האנדרואיד
`il.avimak.TehillatHashem`. הזכויות שייכות לבעליהן.
מכיוון שהתוכן הוא תמונות ולא טקסט, אין באפליקציה חיפוש או העתקת טקסט.
